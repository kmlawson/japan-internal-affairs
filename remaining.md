## Making a batch

Write the PDF names (`f` in data.js) of the chosen files to a list, then run two workers, e.g.:

```
python3 catalog_merged.py --backend agy --model gemini-3.8-flash-high --only only-X.txt \
    --ocr ../merged/ocr,../merged/ocr-batch3,../merged/ocr-batch4
# second worker: same command with --reverse
```
Then `python3 build_db.py && python3 build_sets.py && python3 build_spotlight.py && python3 remaining.py`, and rebuild the full-text index (fulltext-build/) so the new documents are searchable by document.
