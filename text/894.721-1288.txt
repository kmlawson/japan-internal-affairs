Japanese Administration notifies effective July 22nd application of censorship telegrams in code language suspended for all places except when destined Tokyo Yokohama Osaka and Kobe to these four points following codes admitted: Oriental improved three letter code (ori) Oriental self checking three letter (erith) schofields safe check three letter (scho) bentleys second phrase (benses) bentleys complete phrase (bensam) name commodity and phrase (aams) standard abbreviation for codes must be transmitted following the check to all other destinations in Japan telegrams must be in plain Japanese German or English language these three languages also admitted telegrams to Tokyo Yokohama Osaka and Kobe registered code addresses not admitted in the address nor as signatures signature either in the form of firm name or individual surname obligatory reply paid (RP) not admitted radio service to mobile stations suspended except for distress or urgent telegrams

B R ALLEN
